# Web vulnerability narrative

Structure each finding for client text:
1. Title + severity (from MCP, never inflate)
2. Affected asset (host/URL) + scan id
3. What was observed (evidence snippet only; no payloads)
4. Business impact in plain language
5. Remediation (owner + action; no attack how-to)

Prefer grouping same-template hits by host. Cite `vulnerability_id` and `scan_id`.
